# Квест-игра «Школьные Земли»

Мини-приложение для MAX с использованием Python (FastAPI + SQLite), веб-интерфейса (HTML/CSS/JS) и чат-бота.

## 🛠 Предварительные требования
Для запуска проекта вам понадобятся:
1. **Docker** и **Docker Compose** (установлены и запущены).
2. **Git** (для клонирования репозитория).
3. Токен чат-бота MAX (получается в кабинете разработчика MAX).

## 📂 Структура проекта
- app/ — фронтенд мини-приложения (HTML, CSS, JS, картинки).
- bot/ — логика чат-бота MAX.
- api.py — сервер API (FastAPI) и база данных SQLite.
- Dockerfile — инструкция для сборки Python-контейнера.
- docker-compose.yml — конфигурация для одновременного запуска API и бота.

## 🚀 Пошаговая инструкция по запуску

### Шаг 1. Клонирование репозитория
Откройте терминал и склонируйте проект на свой компьютер:
```
git clone https://github.com/ваш-логин/название-репозитория.git
cd название-репозитория
```

### Шаг 2. Настройка переменных окружения
В корне проекта найдите файл .env.example. Создайте на его основе новый файл .env:
```
cp .env.example .env
```
Откройте созданный файл .env любым текстовым редактором и заполните данные:
```
BOT_TOKEN=1234567890:ваш_токен_из_кабинета_max
BOT_USERNAME=ваш_юзернейм_бота
WEBAPP_URL=https://ваш-сайт.com
```

Примечание: WEBAPP_URL понадобится, если вы будете привязывать мини-приложение к боту в настройках MAX.

### Шаг 3. Сборка и запуск контейнеров
Убедитесь, что Docker запущен. В терминале (в корне проекта) выполните команду:
```
docker-compose up --build -d
```

**Что произойдет:**
1. Docker скачает образ Python.
2. Установит все зависимости из requirements.txt.
3. Запустит сервер API и базу данных на порту 8000.
4. Запустит чат-бота в фоновом режиме.

### Шаг 4. Проверка работы
После успешного запуска проверьте работу всех частей проекта:

1. **Веб-интерфейс (Мини-апп)**:
   Откройте в браузере: http://localhost:8000
   Вы должны увидеть экран приветствия «Школьные Земли» с выбором роли.

2. **API Документация (Swagger)**:
   Откройте в браузере: http://localhost:8000/docs
   Здесь можно вручную протестировать методы API.

3. **База данных**:
   В корне проекта появится файл database.db. Вы можете открыть его через программу DB Browser for SQLite, чтобы проверить, как сохраняются задания и статистика.

4. **Чат-бот**:
   Найдите вашего бота в MAX и отправьте ему команду /start. Убедитесь, что он отвечает и присылает кнопку.

## 🛑 Остановка проекта
Чтобы остановить и удалить контейнеры, выполните команду в терминале:
```
docker-compose down
```

## 📝 Тестовый сценарий для проверки MVP
1. В веб-интерфейсе нажмите «Вход для учителя», введите любое имя.
2. Введите три тестовых уравнения (например: 2x=4 ответ 2) и нажмите «Сохранить задания».
3. Выйдите из аккаунта учителя и нажмите «Вход для ученика».
4. Введите имя и решите три уравнения. Обратите внимание на смену меча (зачарование) и этапы битвы с боссом.
5. После победы или поражения вы перейдете на страницу статистики, где отобразятся данные из базы SQLite.

## 📦 Запуск без Docker (для локальной разработки)
Если вы хотите запустить проект без Docker:
1. Установите зависимости: pip install -r requirements.txt
2. Запустите API: uvicorn api:app --reload --port 8000
3. Запустите бота (в новом терминале): python main.py
4. Откройте http://localhost:8000 в браузере.
